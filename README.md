## 🌟 Key Capabilities & Modules

* **🛡️ Security & Threat Hunter:** Built-in Honeytokens, JIT Privilege Elevation, Attack Path mapping, and DLP/PII scanning.
* **📊 Executive Reporting:** One-click Executive PDF reports, instant Security Scorecards, and real-time Domain Compliance ratings (e.g. 98% Healthy).
* **🔍 Fast Forensics & Helpdesk Tools:** 
  * **Machine Forensics (Kundali):** Deep-dive system state analysis.
  * **Lockout Diagnostics:** Fast root-cause tracking for locked accounts.
  * **Stale Archiver:** Automated inactive user/computer cleanup.
* **⚡ MMC Quick Tools Integration:** Instant 1-click access to ADUC, GPMC, DNS, DHCP, Event Viewer, and Services.
* **📈 Live Telemetry:** Real-time monitoring for Domain Controllers, Network Connectivity, AD Sync Engine, Intune Gateway, and SIEM Syslog.
